#### How do we know which class each object belongs to? Evaluate the following expressions (¿Cómo sabemos a qué clase pertenece cada objeto? Evalúa las expresiones).


#### a)
```smalltalk
#(Francesca Jackie Marisa Bree) class

Result: Array
```

#### b)
```smalltalk
'Rakesh Vijay Charles Daniel Tyler' class

Result: ByteString
```

#### c)
```smalltalk
5 class

Result: SmallInteger
```

#### d)
```smalltalk
(1/2) class

Result: Fraction
```

#### e)
```smalltalk
5.2 class 

Result: SmallFloat64
```
