# Evaluate de following binary messages.
# Evalúe los siguientes Mensajes Binarios.

##Nota: El operador "," concatena colecciones.

#### a)
```smalltalk
'Hola', ' aquí estoy'

Result: 'Hola aquí estoy'
```

#### a)
```smalltalk
#(1 2 3), #(4 5 6)

Result: #(1 2 3 4 5 6)
```

#### a)
```smalltalk
5 = 4 

Result: false
```

#### a)
```smalltalk
#(1 2 $a), #($b 'cd')

Result: #(1 2 $a $b 'cd')
```
